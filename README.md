## 这里有什么

目前只有 [`LICENSE`](LICENSE)（MIT）和一个 README。仓库描述写的是「测试」，
所以它大概是当初用来试 Git 操作的。

## 能用来干什么

留着一个空仓库其实挺有用：

- **试 Git 操作** —— rebase、cherry-pick、revert 这些练手，搞坏了不影响正经项目
- **存临时脚本** —— 一次性用的东西，不值得开一个正式仓库
- **当 GitHub Actions 实验田** —— 试 workflow 语法，跑失败了不心疼
